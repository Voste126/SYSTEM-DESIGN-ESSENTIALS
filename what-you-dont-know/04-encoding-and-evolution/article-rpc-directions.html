The actual tradeoff: custom binary RPC vs. REST

A purpose-built binary protocol can genuinely outperform generic JSON over REST. But REST wins on things raw performance doesn't erase.

REST's real advantages: you can poke it directly with a browser or curl, zero code generation needed; it's supported by every mainstream language and platform; and there's a massive existing ecosystem — caches, load balancers, proxies, firewalls, monitoring tools — all built to understand HTTP natively. This is exactly why REST dominates public-facing APIs, while RPC frameworks concentrate on internal service-to-service calls within one organization, where the performance edge matters more and the tooling gap matters less.
